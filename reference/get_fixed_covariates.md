# Identify covariates with FIX status

Checks both covariate_search data and model THETA parameters to identify
covariates that should not be removed

## Usage

``` r
get_fixed_covariates(search_state, covariate_names)
```

## Arguments

- search_state:

  List containing search state

- covariate_names:

  Character vector. Covariate names to check

## Value

Character vector of fixed covariate names
