# Forest-plot ggplot2 Theme

A clean black-on-white `theme_bw()` variant used for the covariate /
exposure forest plots (inward ticks, bordered panel, black text).

## Usage

``` r
theme_forest(base_size = 12, base_family = "")
```

## Arguments

- base_size:

  Base font size. Default 12.

- base_family:

  Base font family. Default "".

## Value

A ggplot2 theme object to add to a plot.
