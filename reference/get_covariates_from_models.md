# Extract covariate names from specific models

Returns unique covariate names that were tested in the specified models

## Usage

``` r
get_covariates_from_models(search_state, model_names)
```

## Arguments

- search_state:

  List containing search state

- model_names:

  Character vector. Model names to extract covariates from

## Value

Character vector of unique covariate tag names
