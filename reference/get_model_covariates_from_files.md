# Extract covariates from model using BBR tags

Gets covariate information from BBR model tags

## Usage

``` r
get_model_covariates_from_files(search_state, model_name)
```

## Arguments

- search_state:

  List containing search state

- model_name:

  Character. Model name

## Value

Character vector. Covariate names

## Details

Get Model Covariates from Files
