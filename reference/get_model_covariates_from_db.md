# Get all covariates in a model by tracing hierarchy

Traces model hierarchy to get all covariates in a model

## Usage

``` r
get_model_covariates_from_db(search_state, model_name)
```

## Arguments

- search_state:

  List containing search state

- model_name:

  Character. Model name

## Value

Character vector. All covariate names in the model

## Details

Get Model Covariates from Database (Cumulative)
