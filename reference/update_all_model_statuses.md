# Updates all models with robust error handling and concise progress reporting

Refreshes every active model's status from its NONMEM output files

## Usage

``` r
update_all_model_statuses(search_state, show_progress = TRUE)
```

## Arguments

- search_state:

  List. Current search state

- show_progress:

  Logical. Whether to show progress summary (default: TRUE)

## Value

List with updated search_state

## Details

Update All Model Statuses
