# Extract OFV from completed model database entry

Fast lookup of cached OFV value from search database

## Usage

``` r
get_model_ofv_from_database(search_state, model_name)
```

## Arguments

- search_state:

  Search state object

- model_name:

  Model name

## Value

Numeric OFV or NA if not found

## Details

Get Model OFV from Database
