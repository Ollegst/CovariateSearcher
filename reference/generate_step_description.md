# Generate Step Description (VECTORIZED VERSION)

Generate Step Description (VECTORIZED VERSION)

## Usage

``` r
generate_step_description(step_number, action, covariate_tested)
```

## Arguments

- step_number:

  Integer vector of step numbers

- action:

  Character vector of action types

- covariate_tested:

  Character vector of covariate names

## Value

Character vector of step descriptions
