# Extract maximum RSE from model using existing functionality

Wrapper around get_param2 to extract max RSE value

## Usage

``` r
get_model_max_rse(search_state, model_name)
```

## Arguments

- search_state:

  List containing search state

- model_name:

  Character. Model name

## Value

Numeric. Maximum RSE value or NA
