# Get current status of a model from database

Checks model completion status from search database

## Usage

``` r
get_model_status(search_state, model_name)
```

## Arguments

- search_state:

  List containing search state

- model_name:

  Character. Model name to check

## Value

Character. Status: "completed", "failed", "in_progress", etc.
