# Display SCM results table with RSE and evaluation comments

Print Enhanced SCM Results Table

## Usage

``` r
print_scm_results_table(
  search_state,
  show_rse = TRUE,
  truncate_covariates = 35
)
```

## Arguments

- search_state:

  List containing search state

- show_rse:

  Logical. Whether to show RSE column (default: TRUE)

- truncate_covariates:

  Integer. Max characters for covariate column (default: 35)
